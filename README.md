# IT Inventory

Static marketing site for an IT Inventory platform. Includes:

- `index.html` — marketing landing page with hero, categories, features, and contact form.
- `stats.html` — lightweight dashboard page showing utilization, refresh counts, and category breakdowns.
- `styles.css` — global styling with a dark professional theme.
- `script.js` — small enhancements for the current year, animated bars, and sparkline visualizations.

Open `index.html` in your browser to explore the experience.
