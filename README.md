# IT Inventory

Static marketing site for an IT Inventory platform. Includes:

- `index.html` — marketing landing page with hero, categories, workflow process, testimonial, and contact form.
- `stats.html` — dashboard page showing utilization, category breakdowns, live tables, and renewal timelines.
- `styles.css` — global styling with a dark professional theme.
- `script.js` — enhancements for the current year, animated bars, sparkline visualizations, and data-driven stats widgets.

Open `index.html` in your browser to explore the experience.
